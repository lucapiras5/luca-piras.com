## Useful keybindings

*C-p* and *C-n* will move between the previous/next command in the history.*C-r* lets you search backwards in history. Start typing, then hit *C-r* again to search backwards again.

*C-z* will pause the current command. Use *jobs* to show paused commands. *fg* will resume the last paused job.

*C-w* deletes the last word. *M-d* deletes the next word. *C-u* deletes the line from the beginning to the cursor, *C-k* deletes from the cursor to the end. *C-/* undoes the last change. *C-x C-e* will open *$EDITOR* with the current command line.

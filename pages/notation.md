## Keyboard shortcuts: Control and Alt

*Ctrl* is abbreviated to *C-*, and *Alt* is abbreviated to *M-*. *Ctrl-Alt-* is *C-M-*.

*Alt* can also be typed in terminals by pressing *Esc*. That is, *C-M-f* can also be typed as *ESC C-f*.

Terminal apps do not distinguish between upper- and lowercase, so the letter will always be in lowercase. If GUI apps require the use of the Shift Key, it will be noted explicitly.

## Root and user commands

Commands meant to be typed in a shell are prefixed with *$*. Commands that should be run as the root user are prefixed with *#*.

One can become root user using *sudo*, *doas*, or *su*.
